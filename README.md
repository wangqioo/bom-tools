# BOM 转换工具 v5.10

客户 BOM 格式转换脚本，将含有多供应商信息的 BOM 展开为多行，便于内部评审或上传 PLM 系统。

---

## 环境要求

- Python 3.8 及以上
- 依赖库：`openpyxl`（首次运行时若未安装，脚本会自动安装）

脚本可放置在任意路径，无需与 BOM 文件放在同一文件夹。

---

## 使用方式

双击运行，或在终端执行：

```
python bom_gui.py
```

---

## 操作步骤

### 第一步：选择文件

- 点击「浏览...」选择客户 BOM 的 Excel 文件（`.xlsx` / `.xlsm` / `.xls`）
- 选择对应的 Sheet 和表头行（默认第 1 行）
- 底部预览区显示前 5 行内容，可确认是否选对

### 第二步：列映射

脚本会自动扫描并识别各列用途，扫描结果显示在下方文本框中。

可手动调整以下列位置（填列字母，如 `A`、`D`）：

| 字段 | 说明 |
|---|---|
| 物料名称列 | 物料品名/描述所在列 |
| 用量列 | 用量/数量所在列 |
| 品牌/厂家列 | 见下方格式说明 |
| 型号列 | 格式 B/C 需填写；格式 A 无需填写 |

**格式选择：**

| 格式 | 说明 | 示例 |
|---|---|---|
| 格式 A | 品牌型号合并在一列，`\|\|` 或空格分隔 | `MURATA:GRM188\|\|SAMSUNG:CL10` |
| 格式 A | 同上，单空格分隔多对 | `KOA:RK73B2 YAGEO:RC0805 FENGHUA:RS-05K` |
| 格式 B | 厂家列和型号列分开，分号分隔多个 | 厂家列：`YAGEO;KOA`，型号列：`RC0805;RK73` |
| 格式 C | 制造商列含编号，冒号分隔 | `1630-大毅科技[全称]:0362-RALEC[全称]` |

> 选择格式 A 时，型号列输入框自动禁用，无需填写。

### 第三步：输出设置

选择输出模式：

| 模式 | 说明 |
|---|---|
| 原格式展开 | 保留客户 BOM 所有列，供应商拆成多行 |
| 转为 HQ 格式 | 输出为整机 BOM 配置表（需填写项目名称） |

输出文件默认保存在**与输入文件相同的目录**，文件名为 `展开多行BOM.xlsx` 或 `内部评审BOM.xlsx`。

若同名文件已存在，自动在文件名末尾追加序号，如 `展开多行BOM(1).xlsx`，不会覆盖原文件。

点击「开始转换」后自动跳转至日志页，转换完成后弹出提示并自动打开文件所在文件夹。

---

## 输出格式说明（原格式展开模式）

| 列位置 | 内容 |
|---|---|
| 第一列（新增） | **序号**：同一组替代料共享同一序号，用于标识分组 |
| 中间各列 | 保留客户 BOM 原有列；品牌型号合并列（格式 A）拆为「厂商」+「型号」两列 |
| 最后一列（新增） | **是否独供**：仅有一个供应商填「是」；存在替代料填「否」（主供行和替代料行均填「否」） |

**行规则：**
- 主供行：完整保留原 BOM 的所有列数据
- 替代料行：仅填写厂商、型号，其余列留空

---

## 示例

原始 BOM（格式 A）：

| 物料名称 | 用量 | 品牌型号 |
|---|---|---|
| 电阻 271Ω | 2 | KOA:RK73B2 YAGEO:RC0805 FENGHUA:RS-05K |
| 电容 100nF | 1 | MURATA:GRM188 |

转换后输出：

| 序号 | 物料名称 | 用量 | 厂商 | 型号 | 是否独供 |
|---|---|---|---|---|---|
| 1 | 电阻 271Ω | 2 | KOA | RK73B2 | 否 |
| 1 | | | YAGEO | RC0805 | 否 |
| 1 | | | FENGHUA | RS-05K | 否 |
| 2 | 电容 100nF | 1 | MURATA | GRM188 | 是 |
