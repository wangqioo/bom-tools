# BOM Tools

企业内部硬件设计辅助工具集，包含 BOM 格式转换、PLM 上传、飞书优选库匹配、原理图分析等脚本。

---

## 目录结构

```
bom-tools/
├── scripts/        # CLI 工具脚本（单机运行）
│   ├── bom_gui.py               BOM 格式转换
│   ├── plm_upload.py            PLM 批量上传
│   ├── feishu_multi_matcher.py  飞书多表匹配
│   ├── pstx_analyzer.py         Cadence 原理图分析
│   └── csa_checker.py           CSA 几何规范检查
├── web_app/        # Flask Web 统一界面（推荐）
├── deploy_bundle/  # 离线部署包（Windows 无网环境）
└── CHANGELOG.md
```

### CLI 工具一览

| 脚本 | 功能 | 版本 |
|---|---|---|
| `scripts/bom_gui.py` | 客户 BOM 格式转换，将多供应商 BOM 展开为多行 | v5.10 |
| `scripts/plm_upload.py` | BOM 批量上传至 PLM 系统 | - |
| `scripts/feishu_multi_matcher.py` | 飞书多表格匹配，预置14库分优选/对应关系双类，多键AND匹配 | v3.0 |
| `scripts/pstx_analyzer.py` | Cadence 原理图分析工具（BOM / DRC / 降额 / 查询 / 层次化页码） | v1.3 |
| `scripts/csa_checker.py` | CSA 几何规范检查工具（DOT 四向十字 / 画圈检测） | v1.0 |

### 🌐 Web 版（推荐）

所有工具已整合到统一的 Flask Web 界面，支持多人在线使用：

cd web_app

## bom_gui.py — BOM 格式转换工具

将含有多供应商信息的客户 BOM 展开为多行，便于内部评审或上传 PLM 系统。

### 使用方式

```bash
python scripts/bom_gui.py
```

### 操作步骤

**第一步：选择文件**

- 点击「浏览...」选择 Excel 文件（`.xlsx` / `.xlsm` / `.xls`）
- 选择 Sheet 和表头行（默认第 1 行）
- 底部预览区显示前 5 行内容

**第二步：列映射**

脚本自动扫描各列用途，可手动调整：

| 字段 | 说明 |
|---|---|
| 物料名称列 | 物料品名/描述所在列 |
| 用量列 | 用量/数量所在列 |
| 品牌/厂家列 | 见下方格式说明 |
| 型号列 | 格式 B/C 需填写；格式 A 无需填写 |

**格式选择：**

| 格式 | 说明 |
|---|---|
| 格式 A | 品牌型号合并一列，`\|\|` 或空格分隔，如 `KOA:RK73B2 YAGEO:RC0805` |
| 格式 B | 厂家列和型号列分开，分号分隔多个 |
| 格式 C | 制造商列含编号，冒号分隔 |

**第三步：输出设置**

| 模式 | 说明 |
|---|---|
| 原格式展开 | 保留客户 BOM 所有列，供应商拆成多行 |
| 转为内部格式 | 输出为整机 BOM 配置表（需填写项目名称） |

输出文件默认保存在与输入文件相同目录。若同名文件已存在，自动追加序号，不覆盖原文件。

## pstx_analyzer.py — Cadence 原理图分析工具

解析 Cadence Packager-XL 导出的 `.dat` 网表文件，提供 BOM 管理、网络拓扑分析、设计检查（DRC）、电容降额分析、元件/网络查询等功能，并支持导出多 Sheet Excel 报告。

单文件脚本，无需额外模块，首次运行自动安装 `openpyxl`。

### 使用方式

```bash
python scripts/pstx_analyzer.py
```

### 输入文件

Cadence OrCAD / Allegro 执行 Packager-XL 后自动生成以下文件：

| 文件 | 必须 | 说明 |
|---|---|---|
| `pstxprt.dat` | ✅ | 元件属性（位号、料号、封装、耐压、精度等） |
| `pstxnet.dat` | ✅ | 电气网络连接关系（引脚 → 网络映射） |
| `pstxref.dat` | 可选 | 元件与原理图符号的交叉参考索引 |

**推荐加载方式：** 在「文件加载」Tab 点击「选择文件夹…」，选择 worklib 中该项目的文件夹，工具将自动识别并填入三个文件路径。也可单独点击各文件右侧的「浏览…」手动选择。

### 功能说明

| Tab | 功能 |
|---|---|
| 文件加载 | 文件夹自动识别或手动选择，解析后显示概览统计 |
| BOM 管理 | 按贴装 / DEPOP / 全部筛选，实时搜索，导出 Excel |
| 网络分析 | 电源网络、GND、差分对识别，单端网络（疑似漏连）提醒，各页面元件数统计 |
| 设计检查 | 缺料号 / 缺 VALUE / 缺封装 / TBD 属性 / BOM_OPTION 拼写错误检测 |
| 电容降额 | 从网络名推断工作电压，计算额定/工作电压比，可调降额系数，内置 30+ 条电压匹配规则，支持自定义映射 |
| 元件查询 | 按位号或网络名查询，精确 + 模糊匹配，显示完整属性及引脚连接 |
| 日志 | 操作全程记录 |

### 电容降额说明

工具通过分析电容所连接的**网络名**推断其工作电压，规则示例：

| 网络名包含 | 推断工作电压 |
|---|---|
| `P12V`、`12V` | 12 V |
| `P3V3`、`3V3` | 3.3 V |
| `P1V8`、`1V8` | 1.8 V |
| `GND`、`AGND`… | 0 V（不计入） |
| … | 共 30+ 条规则 |

若网络命名不规范（如 `NET_A`），可在界面的「自定义电压映射」框中手动补充（每行 `NET前缀=电压V`）。点击「查看内置电压匹配规则 ▾」可展开完整规则列表及算法说明。

降额合格标准：**额定电压 ÷ 工作电压 ≥ 降额系数**（默认 2.0，界面可调）。

### 导出 Excel

点击「BOM 管理」页右下角「导出 Excel」，生成包含以下 Sheet 的 `.xlsx` 报告：

| Sheet | 内容 |
|---|---|
| 概览 | 元件数、网络数、DRC 问题数等汇总指标 |
| BOM_贴装 | 贴装元件汇总（按类型 + 料号排序，含数量） |
| BOM_DEPOP | DEPOP 元件汇总 |
| BOM_明细 | 所有位号的完整属性明细 |
| 网络分析 | 电源网络 / GND / 差分对 / 单端网络分段列表 |
| 设计检查 | 各类 DRC 问题分段列表 |
| 降额分析 | 电容降额计算结果，不合格行红色背景 |
