# 飞书在线库删除线过滤升级记录

## 背景

飞书优选库 + 关系库匹配目前已支持在线 Sheet 缓存、关系库优先级、命中关系库后继续带出优选库命中，以及单 Sheet 的“优选可替代推荐”开关。

业务上还需要支持：飞书在线库中如果某一行任意单元格带删除线，则整行不参与缓存和匹配。

## 当前状态

该功能暂未启用。

原因是现有飞书中台读取单元格值接口只能返回值，不能稳定返回字体删除线等格式信息。之前尝试通过导出在线表格为 xlsx 后读取格式，但接口返回权限不足：

```text
code: 99991672
msg: Access denied. One of the following scopes is required: [drive:export:readonly, docs:document:export]
```

因此当前应用无法安全判断删除线行。如果强行只按值接口判断，会漏掉“整行删除线但仍有值”的数据，存在误匹配风险。

## 后续升级点

下次恢复该功能时，需要先解决飞书应用权限：

- `drive:export:readonly`
- 或 `docs:document:export`

拿到导出权限后，再实现流程：

1. 缓存 Sheet 时读取在线值数据。
2. 同时导出同一 Sheet 为 xlsx。
3. 用 openpyxl 检查导出文件中每一行任意单元格是否存在 `font.strike == True`。
4. 只要该行任意单元格有删除线，就整行过滤，不写入服务端缓存。
5. 缓存接口返回过滤行数，前端显示“已过滤删除线行 N 行”。

## 注意

该功能依赖飞书导出权限，不是普通 `getSheetsValue` 读值接口可以完成的问题。若后续再问“为什么删除线过滤没有开启”，请先检查飞书应用是否已补齐上述 scope。
