# 飞书优选库+关系库匹配工具实现逻辑

## 工具定位

该工具用于把本地 BOM 和飞书优选库、关系库进行多表匹配。用户可以配置多个飞书表格、多个 Sheet、多个匹配键，并选择需要带回的字段。

前端入口：`data-tool="feishu"`。
后端模块：`web_app2/feishu/__init__.py`。

## 飞书数据读取

飞书访问通过公司内部网关完成。网关地址由 `_resolve_feishu_base_url()` 校验，目前只允许系统预设地址，避免任意 URL 请求。

主要函数：

- `_hq_get_sheets()`：获取飞书表格 Sheet 元信息。
- `_hq_read_sheet()`：按 range 分批读取 Sheet 数据。
- `_write_cache()`：把 Sheet 全量数据写入服务端缓存。
- `_read_cache()`：按 cache key 读取缓存。

缓存粒度是 `token + sheet_id`，文件保存在 `web_app2/cache/feishu_<key>.json`。

## 主要接口

### `/api/feishu/sheets`

根据 token 获取 Sheet 列表，并读取每个 Sheet 第一行作为表头。前端用这些表头做字段配置。

### `/api/feishu/load`

读取指定 Sheet 全量数据并写入缓存。返回 `cache_key`、数据行数、表头、缓存时间。

### `/api/feishu/local_sheets`

读取本地 Excel 的 Sheet 和表头，供前端选择本地匹配键。

### `/api/feishu/match`

执行正式匹配并生成 Excel。

## 匹配配置

每个飞书 Sheet 可配置：

- 是否启用。
- 本地匹配键列表。
- 飞书匹配键列表。
- 需要提取的飞书字段。
- 字段别名映射。
- 缓存 key。

本地键和飞书键数量必须一致。匹配逻辑是多字段 AND 匹配，即多个键组合成一个元组。

## 核心匹配流程

1. 上传本地 BOM，并读取本地表头。
2. 遍历所有启用的飞书 Sheet 配置。
3. 优先读取服务端缓存；缓存不存在时尝试实时读取飞书。
4. 校验本地键和飞书键是否存在。
5. 为每个飞书 Sheet 构建 lookup：`(key1, key2, ...) -> [row_dict]`。
6. 遍历本地 BOM 行，按本地键组成元组。
7. 依次查找准备好的飞书表。
8. 匹配成功时输出本地原始列、飞书提取列和来源表格。
9. 未匹配时仍输出本地行，并标记来源为“未匹配”。

## 输出文件

输出：`web_app2/outputs/飞书匹配结果_<uid>.xlsx`。

输出列包括：

- 本地 BOM 原始列。
- 用户选择的飞书字段。
- `来源表格`。

返回统计：`total`、`matched`、`unmatched`、`logs`。

## 异常处理

- Token 为空会拒绝。
- Sheet 不存在或删除会报错或跳过。
- 本地键、飞书键不存在会跳过该 Sheet 并写入日志。
- 没有可用 Sheet 时返回失败和处理日志。
