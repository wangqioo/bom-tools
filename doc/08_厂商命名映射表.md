# 厂商命名映射表实现逻辑

## 工具定位

用于维护客户厂商名称、英文大小写变体、中文名、音译名与 HQ 规范厂商名之间的精确映射关系。

前端入口：`data-tool="manufacturer-alias"`。
后端模块：`web_app2/manufacturer_alias/__init__.py`。

## 数据存储

使用 SQLite：`web_app2/manufacturer_aliases/aliases.sqlite3`。

表字段包括：id、HQ 规范厂商名、厂商别名、归一化键、来源、备注、创建时间、更新时间。

`normalized_alias` 有唯一约束，避免同一个别名变体被映射到多个规范厂商名。

## 归一化规则

`normalize_manufacturer_name()` 会执行：

- Unicode NFKC 归一化
- 英文大小写折叠
- 去除空格、下划线、横线、常见中英文标点和括号

示例：`MURATA`、`mu-r_a.t a` 会落到同一个归一化键。

## 主要接口

### `GET /api/manufacturer_aliases?q=...`

查询映射列表。若 `q` 存在，会同时返回精确归一化命中的 `match`。

### `GET /api/manufacturer_aliases/lookup?name=...`

供后续 BOM / 飞书 / PLM 流程复用的轻量查询接口。

### `POST /api/manufacturer_aliases`

新增映射。

必填：HQ 规范厂商名、厂商别名。

可选：来源、备注。

### `DELETE /api/manufacturer_aliases/<alias_id>`

删除指定映射。

## 后续复用方式

后端代码可以直接导入：

```python
from manufacturer_alias import lookup_manufacturer, normalize_manufacturer_name
```

匹配流程中先用 `lookup_manufacturer(customer_vendor)` 取得 HQ 规范厂商名，再参与精确匹配。
