# BOM Tools 工具逻辑报告索引

本目录记录 `web_app2` 每个页面工具的实现处理逻辑，便于交接、维护和部署排查。

| 工具 | 报告文件 | 后端模块 |
|---|---|---|
| BOM 格式转换 | `01_BOM格式转换.md` | `web_app2/bom/__init__.py` |
| 飞书优选库+关系库匹配 | `02_飞书优选库关系库匹配.md` | `web_app2/feishu/__init__.py` |
| 查询BOM优选率 | `03_查询BOM优选率.md` | `web_app2/feishu/__init__.py` |
| 转换为上传PLM系统格式 | `04_PLM上传格式转换.md` | `web_app2/plm/__init__.py` |
| BOM比对工具合集 | `05_BOM比对工具合集.md` | `web_app2/bom_compare/__init__.py` |
| Bug提交栏目 | `06_Bug提交栏目.md` | `web_app2/bug_report/__init__.py` |
| 需求开发工单 | `07_需求开发工单.md` | `web_app2/feature_request/__init__.py` |

公共入口：`web_app2/app.py` 注册所有 Blueprint，并提供首页 `/` 与下载接口 `/download/<filename>`。

公共模块：`web_app2/shared.py` 提供上传目录、输出目录、飞书缓存目录、Excel 打开、上传文件保存、表头行校验、飞书网关白名单等能力。

前端入口：`web_app2/templates/index.html` 中的 `TOOLS` 对象负责左侧导航和模板切换。每个工具对应一个隐藏 HTML 模板和一个初始化函数。
