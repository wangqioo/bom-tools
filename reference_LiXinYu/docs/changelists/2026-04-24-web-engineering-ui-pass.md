# 2026-04-24 Web 工程审美对齐优化

## 对比结论

- 生成概念图更像工程审查控制台：固定产品侧栏、项目状态顶栏、KPI 横条、表格优先、右侧上下文检查器。
- 上一版真实页面更像概览报告：顶部和概览卡片更重，查询区位于表格之前，首屏表格露出不足。

## 变更摘要

- 报告页布局改为固定左侧产品 rail、顶部项目状态条、中间主工作区、右侧检查器的工程控制台结构。
- 左侧导航新增 `PSTX` 品牌区和导航标识块，折叠后保留短标识。
- 顶部栏改为项目状态表达：`项目 + 项目名 + 分析完成 + 生成时间 + localhost only + 操作按钮`。
- KPI 区改为横向滚动 dock，并为指标增加工程化短标识。
- 分区入口改成横向紧凑条，输入文件与快速摘要改为折叠详情。
- 查询区移动到报告分区之后，首屏优先展示 BOM/网络/DRC 等主表格。
- 报告分区标题和表格工具栏进一步压缩，让表格内容更早出现在首屏。

## Bug 与修复手段

- Bug：首屏导航 active 状态依赖 IntersectionObserver，截图或弱时序下可能先显示为普通/焦点态。
- 修复：生成导航时默认给 `summary` 链接添加 `is-active`，后续仍由滚动观察器接管。
- Bug：查询区位于主表格之前，用户提交路径后需要先跨过查询面板才能进入审查数据。
- 修复：模板顺序调整为 `summary -> report-sections -> query`，导航顺序同步调整。
