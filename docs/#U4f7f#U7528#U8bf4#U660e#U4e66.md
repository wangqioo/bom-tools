## 1 环境要求与安装

### 依赖

| 依赖 | 版本要求 | 说明 |
|------|---------|------|
| Python | 3.8 及以上 | 系统自带 tkinter |
| openpyxl | 任意 | Excel 导出；程序启动时自动安装 |

### 安装步骤

```bash
# 1. 下载脚本（只需一个文件）
#    从 GitHub 下载 pstx_analyzer.py

# 2. 直接运行（openpyxl 缺失时自动安装）
python pstx_analyzer.py
```

无需 `pip install`，无需虚拟环境，下载即用。

---

## 2 启动程序

```bash
python pstx_analyzer.py
```

首次运行若缺少 `openpyxl`，程序会自动调用 pip 安装后继续启动，无需手动操作。

## 3 界面概览

程序启动后显示一个多标签页窗口，从左到右依次为：

```
[ 文件加载 ] [ BOM 管理 ] [ 网络分析 ] [ 设计检查 ] [ 电容降额 ] [ 电阻检查 ] [ 元件查询 ] [ 日志 ]
```

**工作流程：**

```
1. 文件加载（选择文件 → 开始解析）
        ↓
2. 各分析 Tab 自动填充结果
        ↓
3. 导出 Excel 报告
```

所有 Tab 中的表格均支持**点击列标题排序**（再次点击反向排序，使用自然排序：C1 < C2 < C10）。

## 4 文件加载

### 4.1 所需文件

| 文件 | 内容 | 必填 |
|------|------|------|
| `pstxprt.dat` | 元件属性（位号、料号、封装、电气参数…） | ✅ 必填 |
| `pstxnet.dat` | 网络连接（哪些引脚连在一起） | ✅ 必填 |
| 项目根目录 | 用于定位 `sch_1/page*.csv`，获取真实页码 | 可选 |

这三个文件通常位于 Cadence 导出的 `worklib/<项目名>/packaged/` 目录下。

### 4.2 快速加载（推荐）

点击页面顶部的**「选择文件夹，自动识别」**按钮，在弹出的对话框中选择 `worklib` 中该项目的文件夹，程序会自动在该目录及其一级子目录中搜索 `pstxprt.dat` 和 `pstxnet.dat`，并自动填入路径。

> **注意**：请选择 `worklib` 中该项目的根文件夹（即包含 `packaged/` 子目录的那一层），而不是 `packaged/` 目录本身。

### 4.3 手动选择

分别点击三行输入框右侧的**「浏览…」**按钮，手动指定各文件路径。

### 4.4 DEPOP 元件开关

文件加载区底部有一个 **「DEPOP 元件参与分析」** 勾选框：

- **勾选**（默认）：降额分析和电阻检查会包含 DEPOP 元件，输出结果中会标注 `DEPOP=Y`
- **不勾选**：DEPOP/DNP 元件从分析中排除，结果更聚焦

### 4.5 开始解析

填好文件路径后点击蓝色**「开始解析」**按钮，右侧显示旋转状态；解析完成后自动跳转到 BOM 管理 Tab，概览区显示关键统计数字。

## 5 BOM 管理

### 5.1 功能说明

展示解析出的元件列表，支持按贴装/DEPOP/全部筛选，支持关键词搜索。

### 5.2 筛选与搜索

- **贴装元件**：`BOM_OPTION` 不是 DEPOP 的元件
- **DEPOP**：`BOM_OPTION = DEPOP` 的元件（不贴装）
- **全部**：以上两类合并显示

在搜索框中输入任意字符（支持位号、料号、封装等任意字段模糊匹配），表格实时过滤。

### 5.3 表格列说明

| 列 | 说明 |
|----|------|
| 位号 | 元件标识符，如 C1、R5、U3 |
| 料号 | 内部物料编码（HQ_CODE 属性） |
| 值 | 元件值，如 100nF、10kΩ |
| 封装 | PCB 封装，如 0402、SOT23 |
| 类型 | 自动识别的元件类型（CAP/RES/IC 等） |
| 页面 | 所在原理图页面 |

### 5.4 底部统计

左下角显示当前可见行数；右下角「导出 Excel」按钮导出完整分析报告（详见第 12 节）。

## 6 网络分析

### 6.1 汇总栏

顶部文本框显示：网络总数、电源网络数、GND 网络数、差分对数、单端网络数。

### 6.2 子标签页

| 子 Tab | 内容 |
|--------|------|
| 电源网络 | 匹配 VCC/VDD/P\d/VBAT 等关键词的网络，按节点数降序 |
| GND 网络 | 匹配 GND/AGND/PGND/SGND/DGND 的网络 |
| 差分对 | 自动识别的差分对（`_P/_N`、`_DP/_DN`、`.P/.N` 等后缀） |
| 单端网络 | 只有一个节点的网络（**疑似漏连**，需重点检查） |
| 各页面元件数 | 每张原理图页面上的元件数量统计 |

## 7 设计检查（DRC）

自动对原理图数据做多维度合规检查，共 7 个子 Tab：

| 子 Tab | 检查内容 |
|--------|---------|
| 缺料号 | `HQ_CODE` 属性为空的元件（测试点除外） |
| 缺 VALUE | `VALUE` 属性为空的元件 |
| 缺封装 | `PACKAGE` 属性为空的元件 |
| TBD 属性 | `VOLTAGE`/`CURRENT`/`POWER` 中含"TBD"字样的元件 |
| 单端网络 | 只连接一个引脚的网络（非 UNNAMED）|
| BOM_OPTION | 所有有 BOM_OPTION 属性的元件，含拼写风险列（✅合法/❌疑似拼错/⚠未知值） |
| 未命名网络 | 网络名以 `UNNAMED_` 开头的网络 |

**BOM_OPTION 拼写风险说明：**

程序使用编辑距离算法，将填写的值与合法值（DEPOP/OPTION/MAIN/ALT/DNP 等）比较：
- 编辑距离 ≤ 2：`❌ 疑似拼错`（如 DEPO、DEPOB）
- 不在合法列表且距离 > 2：`⚠ 未知值`（如 DNI、NOPOP）
- 在合法列表中：`✅ 合法`

## 8 电容降额分析

检查电容的工作电压是否在额定电压的安全范围内。

### 8.1 参数设置

**工作电压上限百分比（默认 70%）**

拖动滑块设置允许的最高工作电压与额定电压之比：

```
工作电压 ≤ 额定电压 × X%  →  ✅ 合格
工作电压 >  额定电压 × X%  →  ❌ 不合格
```

内部规定一般为 70%，可根据项目需求调整。

**自定义电压映射**

当网络命名不规范（如 `NET_MAIN`）导致工具无法推断电压时，在文本框中手动指定：

```
# 每行一条，格式：网络名前缀=电压（V）
VBUS=5.0
V_BAT=7.4
NET_MAIN=3.3
```

点击**「重新计算」**按钮立即生效。

### 8.2 结果表格

| 状态 | 含义 |
|------|------|
| ✅ 合格 (X.Xx) | 工作电压在合格范围内，括号内为额定/工作电压比 |
| ❌ 不合格 (X.XXx < 70%) | 工作电压过高 |
| ⚪ 无额定电压 | 元件未填写 VOLTAGE 属性 |
| ⚪ 无法推断工作电压 | 连接的网络名无法推断电压 |
| ⚪ PG/OD信号 | 网络为 Power Good / OD 输出，电压由外部上拉决定，需手动核实 |
| ⚪ 疑似AC耦合 | 电容两端均连差分网络，疑似交流耦合，不做电压推断 |

底部统计栏汇总：合格数 / 不合格数 / 无法判断数。

### 8.3 内置电压推断规则

工具内置 30+ 条网络名→电压的匹配规则（基于正则表达式），涵盖常见命名：

```
P48V → 48V    P24V → 24V    P12V → 12V
P5V  → 5V     P3V3 → 3.3V  P1V8 → 1.8V
P1V5 → 1.5V   P1V2 → 1.2V  P0V9 → 0.9V
GND  → 0V     AGND/PGND/DGND → 0V
...
```

## 9 电阻检查

检查上拉/下拉/串阻相关的设计问题，共 5 个子 Tab：

### 9.1 重复上拉

同一信号网络上有多个上拉电阻时报告。

**判断方法**：电阻一端接电源网络（P3V3/VCC/…），另一端接同一信号网络。

### 9.2 重复下拉

同一信号网络上有多个下拉电阻（一端接 GND）时报告。

### 9.3 串阻分压风险

当信号路径上同时存在串阻和上拉/下拉时，存在分压导致电平抬升/拉低的风险。

**结果分级：**

| 状态 | 条件 |
|------|------|
| ❌ 高风险 | 串阻/偏置比 ≥ 0.1（1:10 比例不满足）且偏置阻值 < 1kΩ |
| ⚠ 关注 | 比例不满足或偏置阻值 < 1kΩ，但不满足高风险条件 |
| ✅ 正常 | 串阻/偏置比 < 0.1（串阻 < 上拉的 1/10）|

**设计规则**：串阻与上拉之比应小于 1:10，且上拉越小（< 1kΩ）越需要注意串阻位置。

### 9.4 OD/OC 缺少上拉

检测疑似 OD（开漏）/OC（开集）输出信号是否有上拉电阻。

判断依据（多证据组合）：
- 网络名含 `I2C`/`SDA`/`SCL`/`OC_N`/`FAULT`/`ALERT`/`PRESENT`/`PGD` 等关键词（强证据）
- 连接该网络的驱动端只有一个单向驱动器（弱证据）

### 9.5 芯片 Pin 总览

以元件为维度，列出每颗 IC 的各引脚连接上拉/下拉/串阻情况，方便逐引脚核查。

## 10 元件查询

### 10.1 按位号查询

输入精确位号（如 `C100`）查看该元件的所有属性及引脚→网络映射；若未精确匹配，显示所有包含该字符串的位号列表（最多 50 个）。

### 10.2 按网络名查询

输入网络名（如 `P3V3`）查看该网络上的所有元件引脚；若未精确匹配，显示模糊匹配结果。

## 11 日志

记录解析过程、导出操作、错误信息等。点击**「清空日志」**清除历史记录。

## 12 Excel 导出

点击 BOM 管理 Tab 右下角的**「导出 Excel」**按钮，选择保存路径，程序会在后台生成多 Sheet 的分析报告。

若文件名已存在，自动追加 `(1)`、`(2)` 等序号，不会覆盖原文件。

### Sheet 说明

| Sheet | 内容 |
|-------|------|
| 概览 | 关键数字汇总（元件数、网络数、DRC 问题数、降额不合格数） |
| BOM_贴装 | 贴装元件合并 BOM（按类型+料号排序，含数量、位号列表） |
| BOM_DEPOP | DEPOP 元件合并 BOM |
| BOM_明细 | 每个元件独立一行的完整明细 |
| 网络分析 | 电源网络、GND、差分对、单端网络、页面元件数 |
| 设计检查 | 所有 DRC 检查结果（TBD/缺料号/单端网络/BOM_OPTION 等） |
| 降额分析 | 所有电容降额结果，不合格行红底高亮 |

## 13 常见问题

**Q：解析后所有字段为空，或元件数为 0？**

A：检查是否选错了文件（pstxprt.dat 和 pstxnet.dat 不能互换）；或文件编码问题（工具支持 UTF-8/UTF-16/GB18030，极少数情况下 Cadence 导出的文件编码特殊）。

**Q：降额分析大量显示"无法推断工作电压"？**

A：项目网络命名不按标准（如用 `NET_A` 而非 `P3V3`），工具无法自动识别。在降额 Tab 的"自定义电压映射"文本框中手动添加映射规则，点击「重新计算」即可。

**Q：页面字段全为空？**

A：原理图中未填写 `DRAWING` 属性，或项目根目录未选择导致 `page*.csv` 无法读取。可在文件加载时额外选择项目根目录（含 `sch_1/` 子目录的那一层）。

**Q：表格排序后重新解析，排序是否保留？**

A：不保留。每次点击「开始解析」后，所有表格数据重新加载，排序状态重置。

**Q：程序启动时提示安装 openpyxl 失败？**

A：检查 pip 是否可用，或网络连接是否正常。也可手动运行 `pip install openpyxl` 后再启动程序。
