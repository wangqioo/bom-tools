# Web 多列组合筛选

## 变更摘要

- 在 Web 报告表格工具栏新增“多列筛选”面板，可针对任意字段追加多个条件。
- 多个列条件之间按 AND 关系组合，继续叠加原有关键字筛选、状态/类型筛选和排序逻辑。
- 支持 `包含`、`不包含`、`等于`、`不等于`、`开头是`、`结尾是`、`为空`、`非空` 八类操作。
- “重置”和“清空条件”会同步清理多列筛选状态，并重置大表渐进渲染上限。
- 面板摘要会显示当前有效条件数，便于在折叠状态下确认是否仍有筛选条件生效。

## 工程说明

- 多列筛选状态只保存在前端表格实例中，不改变后端分析结果和导出数据。
- 筛选输入沿用防抖刷新，避免每次键入都立即重绘大表。
- `applyTableState()` 只更新摘要和表格数据，不重建筛选控件，避免输入框焦点和内容在输入过程中丢失。
